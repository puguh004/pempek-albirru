Cara membuka:
1. Ekstrak file ZIP.
2. Buka file index.html menggunakan browser.

Cara memperbarui website di GitHub Pages:
1. Upload seluruh isi folder ini ke root repository pempek-albirru.
2. Timpa file lama jika GitHub menanyakan konfirmasi.
3. Tunggu proses GitHub Pages selesai.

PENTING — Perbarui menu Supabase:
1. Login ke Supabase dan buka project pempek-albirru-website.
2. Buka SQL Editor lalu pilih New query.
3. Buka file UPDATE-MENU-SUPABASE.sql dari paket ini.
4. Salin seluruh isi file tersebut ke SQL Editor.
5. Klik Run satu kali.
6. Buka website dan refresh untuk melihat menu serta harga terbaru.

Menu dan halaman admin memakai Supabase paket gratis. Keranjang tersimpan lokal di browser dan checkout diteruskan ke WhatsApp 0831-8243-5471.
